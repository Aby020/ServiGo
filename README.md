# 🏠 NanoServ – Home Service Booking Platform

NanoServ is a web-based platform that connects users with trusted home service providers. It streamlines the process of discovering, booking, and managing home services through an intuitive and responsive interface.

---

## ✨ Features

- 👤 User authentication
- 🏠 Home service booking
- 📍 Location-based service discovery
- 🔍 Search and filtering
- 📅 Booking management
- 🛠️ Service provider dashboard
- 📱 Responsive interface

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Aby020/Nanoserv.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the development server

```bash
python manage.py runserver
```
